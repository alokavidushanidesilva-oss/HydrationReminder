
# HydrationReminder 💧

## About the Project
HydrationReminder is a mobile application developed
using React Native and Expo.

This application reminds users to drink water
regularly through local notifications.

## Features
- Set water reminder intervals.
- Add custom reminder messages.
- Start and stop reminders.
- View hydration benefits and tips.
- About Developer information.
- Three-tab navigation using Expo Router.

## Technologies Used
- React Native
- Expo
- Expo Router
- Expo Notifications
- TypeScript

## How to Run

1. Install dependencies:

   npm install

2. Start the application:

   npx expo start -c

3. Scan the QR code using Expo Go.
